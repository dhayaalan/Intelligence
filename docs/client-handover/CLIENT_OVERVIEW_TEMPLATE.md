## 4. Proposed Investigation Workflow

The platform follows a clear seven-step investigation process:

```
[ 1. Search Target ] ──────> [ 2. Review Findings ] ──────> [ 3. Check Sources ]
         │                                                            │
         ▼                                                            ▼
[ 7. Generate Dossier ] <──── [ 6. Preserve Evidence ] <─── [ 5. Connect Entities ]
         ▲                                                            │
         └────────────────── [ 4. Build Case ] <──────────────────────┘
```

1. **Target Search:** Investigator submits target into the search bar.
2. **Review Findings:** System queries authorized intelligence sources in parallel.
3. **Check Original Sources:** Investigator verifies original web addresses, dates, and provider responses.
4. **Build Case File:** Promising findings are promoted into an active case file.
5. **Connect Entities:** Relationships between people, companies, and infrastructure are mapped visually.
6. **Preserve Evidence:** Collected payloads are saved in the Evidence Vault with tamper-evident digital fingerprints.
7. **Generate Dossier:** Case summary and evidence citations are exported in [Preferred Report Format].
