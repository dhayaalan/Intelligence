# Investigation Workflow

## Single Unified Workspace

Sential eliminates tool-switching fragmentation. Investigators operate in a continuous workflow:

```text
Login
  ↓
Search Target (Auto-classified)
  ↓
Live Multi-Module Execution
  ↓
Review Correlated Entities & Relationships
  ↓
Promote Target to Investigation Case File
  ↓
Add Notes, View Chronological Activity Timeline
  ↓
Verify Cryptographic Evidence Hashes
```

## Case Entities & Relationship Graph

Cases maintain:
* **Target & Type**: Domain, IP, Email, Person, or Username
* **Timeline Events**: Chronological lifecycle history of discoveries, notes, and status transitions
* **Evidence Vault**: Cryptographically signed evidence records
* **Investigator Notes**: Multi-analyst collaborative commentary
